This static website is served directly by Nginx HTTP Server running on an automated Ubuntu cloud target. Its package, configuration, and service states are strictly enforced by Puppet, deployed by Ansible, and health-monitored in real time by Nagios Core.

Project Purpose

This project demonstrates a production-grade, multi-tool DevOps automation pipeline built on single-responsibility principles without tool overlap or container orchestration.

  • Zero Tool Conflict: Each tool has a clear, non-overlapping ownership boundary.
  • Infrastructure as Code: Entire target environment provisioned reproducibly via Terraform.
  • Configuration Idempotency: Puppet continuously converges Nginx to its desired state.
  • Automated Delivery: Ansible securely deploys website artifacts and configures dependencies.
  • Proactive Health Monitoring: Nagios Core executes active HTTP availability checks.

DevOps Toolchain & Architecture

Terraform
Infrastructure Provisioner

Provisions one Ubuntu target in AWS EC2 (t2.micro), security groups, and key pairs.

Puppet
Desired State Engine

Enforces Nginx package installation, configuration integrity, and running service state.

Ansible
Configuration & Deployer

Installs prerequisites and deploys the static website artifacts via SSH.

Nagios Core
Availability Monitor

Performs real HTTP polling, verifies service uptime, and alerts on service degradation.
